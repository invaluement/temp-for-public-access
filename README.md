# temp-for-public-access
A temporary place to share public files.

## Usage

This repository is used to share public files temporarily. Files placed here are publicly accessible via GitHub.

### How to access files

- Browse files directly on GitHub: [github.com/invaluement/temp-for-public-access](https://github.com/invaluement/temp-for-public-access)
- Download individual files using the raw URL:
  ```
  https://raw.githubusercontent.com/invaluement/temp-for-public-access/main/<path-to-file>
  ```

### Directory structure

- `files/` — General shared files
- `files/text/` — Text documents
- `files/data/` — Data files (CSV, JSON, etc.)

### Notes

- Files shared here are **public** and accessible by anyone.
- This is a **temporary** storage location; files may be removed at any time.
